The thesis

An open page is a free page, and agents have noticed.

I

Agents read. Owners are not paid.

robots.txt asks crawlers to stay out. It does not enforce that and it cannot charge. Blocking an agent throws away the demand. Leaving the page open gives the work away.

II

A bare 402 is not a business.

Pay-per-crawl already exists. The owner still cannot say which agent asked, whether it paid, which page earned the money, or who should be allowed, priced or blocked.

III

The value sits above the paywall.

Identity, policy and settlement, kept together and visible to the owner. That is the product.

The product

Agent Gate, the owner's ledger for agent traffic.

Others control crawler access. Agent Gate makes agent access programmable, identifiable and settled onchain.
